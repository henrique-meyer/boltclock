# BoltClock: real-time lightning data sources
Researched 2026-10-16. **[V]** = I checked this myself today (page fetch or a CORS preflight test). Everything else comes from general knowledge and still needs checking before you commit.

Requirements: individual strike lat/lon, radius up to 100 mi around a GPS point in South Florida, a 30-minute all-clear rule, and current weather, a 1–2 h nowcast, and a condition code for the background graphic. Using one vendor for all of it is a plus.

## Notes
- **Xweather radius limit [V]**: standard access caps the radius at **100 km (~62 mi)**, keeps only the **past 5 minutes**, returns up to 1000 strikes per query, and does not support `within`. To get 100 miles or bbox queries you need the **Lightning Enterprise add-on**. A cheaper workaround is to poll a ≤62 mi circle and treat 100 mi as an extended "watch" ring only if you upgrade. The usual 30-minute rule covers ~10 mi (the 30/30 rule), so 62 mi is already plenty for the alarm itself. Polling every 30–60 s against the 5-minute window loses nothing, but the client has to dedupe strikes by id and keep its own 30-minute history for the countdown.
- The Xweather secret is visible in the browser. Xweather supports domain-restricted keys. Otherwise put it behind a tiny proxy (Cloudflare Worker).
- Sources: https://www.xweather.com/docs/weather-api/endpoints/lightning [V], https://www.xweather.com/pricing, https://www.blitzortung.org/en/cover_your_area.php [V], https://docs.tomorrow.io/reference/data-layers-core [V], https://openweathermap.org/api [V], https://www.visualcrossing.com/resources/documentation/weather-data/lightning/, https://registry.opendata.aws/noaa-goes/, https://www.earthnetworks.com, https://www.dtn.com/weather/

## Recommendation
- **Primary: Xweather.** It has the best FL accuracy (Vaisala NLDN/GLD360), real strike lat/lon, and verified open CORS. The same account covers conditions, a minutely/hourly nowcast and weather codes for the background, so one vendor does everything. Start with a paid Developer/Basic plan (watch the 10x lightning multiplier). Add Lightning Enterprise only if a true 100-mile radius is required.
- **Fallback: NOAA GOES GLM, read through a small worker that filters by radius, with NWS api.weather.gov for weather.** It's free, public domain, covers FL, and is legally safe for public display. It is coarser (~8 km) and slower (~1 min), but fine for a backup and for the 30-minute countdown. Blitzortung is not recommended for a public or commercial product because of its terms and the unofficial endpoint.

## Push/streaming options (researched 2026-10-16)
- **Xweather Webhooks** (https://www.xweather.com/docs/webhooks): pushes data to your server by HTTP POST "with as little delay and latency as possible". The datasets (https://www.xweather.com/docs/webhooks/available-data) include **Lightning (individual strikes as they occur)**, Lightning Analytics, Lightning Flash, **Lightning Threats** (predictive threat polygons, https://www.xweather.com/docs/weather-api/endpoints/lightning-threats), Hail Threats and Alerts. Webhooks are a **premium, separate subscription, sales contact only**. No MQTT or public streaming product was found.
- **NOAA SNS `arn:aws:sns:us-east-1:123901341784:NewGOES19Object`** (https://registry.opendata.aws/noaa-goes/): SNS supports HTTP/HTTPS subscribers directly (https://docs.aws.amazon.com/sns/latest/dg/sns-http-https-endpoint-as-subscriber.html). The endpoint must confirm the SubscriptionConfirmation. Subscribing requires AWS credentials, i.e. **an AWS account** (bucket reads don't). Cost: under SNS pricing, publishes and deliveries are billed to the topic owner (NOAA). The subscriber pays only for its own SQS/Lambda/server, which is effectively free at this volume. (This is my reading of https://aws.amazon.com/sns/pricing/ and not stated on a NOAA page. SNS's free tier includes 100,000 HTTP/S notifications/mo.) GOES-19 publishes every product (thousands/hour), and there is no prefix filter unless you use subscription filter policies on message attributes. An SQS or Lambda subscriber that filters is simpler.
- **NWS:** api.weather.gov is pull-only (alerts as JSON/CAP/ATOM; https://www.weather.gov/documentation/services-web-api). Push options are NWWS-OI (XMPP feed of NWS products, by registration) and NOAAPORT/SBN satellite broadcast. Neither has lightning strikes. GLM is also distributed via NOAAPORT and the GRB broadcast (receive hardware needed).
